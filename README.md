# MarketAI - AI-Powered Marketing Assistant

MarketAI is a comprehensive digital marketing platform designed to help small business owners manage their social media presence, generate high-converting content, and analyze performance using Artificial Intelligence.

## 🚀 Features

### AI Content Tools
*   **Content Studio**: Generate full social media posts with AI-generated captions and hashtags.
*   **Visual Studio**: Create AI-powered visual banners and graphics for your posts.
*   **Caption Generator**: Craft engaging hooks and body text in various brand voices.
*   **Hashtag Generator**: Discover trending and niche-specific hashtags for maximum reach.
*   **Ad Copy Generator**: Create conversion-focused copy using AIDA and PAS frameworks.

### Marketing & Scheduling
*   **Marketing Calendar**: A visual grid to manage your content pipeline.
*   **Automated Publishing**: Direct integration with **Instagram**, **Facebook**, and **YouTube**.
*   **Task Management**: Link specific to-dos to your marketing campaigns.
*   **Campaign Planner**: Organize marketing efforts by goals, budget, and platforms.

### Intelligence & Analytics
*   **Performance Tracking**: Real-time metrics for reach, engagement, and impressions.
*   **Sales Prediction**: AI-driven revenue forecasting based on engagement trends.
*   **Competitor Intelligence**: Strategy teardowns and vulnerability analysis of rivals.
*   **Best Time to Post**: Heatmaps showing when your specific audience is most active.
*   **Sentiment Analysis**: AI breakdown of customer reviews and comments.

## 🛠 Tech Stack

- **Frontend**: React, TypeScript, Tailwind CSS, Lucide React (Icons), Vite.
- **Backend**: Node.js, Express, MongoDB (Mongoose).
- **AI**: OpenAI GPT-3.5/4 API.
- **Integrations**: Meta Graph API (Instagram/Facebook), Google YouTube API.

## 📦 Getting Started

### Prerequisites
- Node.js (v18+)
- MongoDB (Local or Atlas)
- OpenAI API Key
- Meta Developer App (for Instagram/Facebook integration)

### Installation

1.  **Clone the repository**:
    ```bash
    git clone <your-repo-url>
    cd sem-project
    ```

2.  **Backend Setup**:
    ```bash
    cd backend
    npm install
    # Create a .env file based on the provided template
    npm run dev
    ```

3.  **Frontend Setup**:
    ```bash
    cd ../frontend
    npm install
    npm run dev
    ```
